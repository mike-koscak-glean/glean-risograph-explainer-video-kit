# Included Glean Desktop Skills

| Skill | Use it when |
|---|---|
| `risograph-explainer-workflow` | You want end-to-end help or do not know which phase comes next. |
| `shape-risograph-video-story` | The idea, audience, evidence, narrative, use cases, or duration is not approved. |
| `design-risograph-video-storyboard` | The story is approved and needs this specific visual treatment and storyboard. |
| `produce-risograph-explainer-video` | Story and visuals are approved and it is time to script, narrate, animate, mix, render, and validate. |

Generated projects contain all four skills. Start a new Glean Desktop session or run `/reload` after project creation so they are discovered.

The skills share artifacts through `project/STATUS.md`; they do not create separate engines or duplicate source code.
